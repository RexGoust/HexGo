# 本地对局手工冒烟测试

运行 `cargo run`。提交影响本地对局 UI 的改动前，请完成以下检查。

## 启动与布局

1. 确认紧凑六边形网格显示在左侧，状态面板显示在右侧。
2. 确认所有棋盘边均清晰连接，没有重复或缺失的线段。
3. 将窗口缩小至允许的最小尺寸再恢复。棋盘必须始终居中、保持比例且完整可见。
4. 确认简体中文标签清晰可读。应用会依次查找思源黑体、Noto Sans CJK、文泉驿正黑、微软雅黑或苹方；如果均不可用，则先记录英文警告，再回退到 Bevy 默认字体。

## 鼠标对局

1. 悬停多个空交点。与当前执子方颜色一致的半透明棋子必须跟随最近交点。
2. 点击空交点。棋子必须出现，当前执子方必须切换，最后落子处必须显示橙色标记。
3. 点击已有棋子的交点。棋盘和当前执子方必须保持不变，面板必须显示交点已占用错误。
4. 完成一个简短提子过程。引擎接受落子后，被提棋子必须立即消失。
5. 在存在合适局面时尝试自杀和违反全局同形的落子。每次拒绝都必须保持棋盘与当前手不变，并显示对应错误。

## 窄屏与触控布局

网页端运行 `trunk serve`，打开输出的网址。检查电脑（1280×800）和手机（360×640、390×844）视口，不刷新页面直接调整尺寸，并旋转手机。画布必须跟随浏览器视口变化（包括手机浏览器工具栏变化），棋盘不得拉伸，点击位置不得偏移。窄屏下状态文字必须自动换行。

测试游戏本身之前，请禁用浏览器缓存并限制网络速度。确认网页加载界面持续更新已下载大小和总大小、稳定的下载速度、预计剩余时间以及最终达到 100% 的进度。下载结束后，界面必须提示游戏正在启动，并且只能在初始化成功后消失。缓存 WASM 后重新加载，确认加载界面仍能正常过渡且不会保留旧数据。启用离线模式，确认页面保留易于理解的失败提示，并将焦点移至“重新加载”按钮。在上述每种电脑和手机视口中重复这些检查，同时验证减少动态效果的浏览器设置。

1. 将窗口调整为竖屏方向（如 360×640 或 390×844）。确认对局内控制区移动到棋盘下方，操作按钮紧凑排列，并隐藏仅供桌面端使用的标题与键盘提示。在手机竖屏的 AI 配置菜单中，确认难度选项自动转为垂直纵向排列且不超出屏幕边界。切换到横屏（如 800×360 或 640×360）时，确认控制区位于右侧边缘，棋盘保持宽大居中且完整可见。
2. 确认棋盘在竖屏和横屏模式下均居中且完整可见，与控制面板没有重叠。
3. 在支持触控的设备上轻触多个空交点，确认每次轻触只在最近的交点落下一枚棋子。
4. 轻触控制面板中的操作按钮，确认该操作不会同时在棋盘上落子。
5. 在支持触控的设备上打开“游戏规则”，分别向上和向下滑动规则正文，确认内容沿对应方向滚动且不会越过边界。关闭弹窗后，确认对局状态保持不变。
6. 结束一局并确认对局结果弹窗正常显示。恢复桌面端宽屏横向窗口后，确认详细结果卡重新显示。

## 键盘对局

1. 按 `Tab` 直到棋盘获得焦点。使用四个方向键移动交点焦点，并使用 `Enter` 或 `Space` 落子。
2. 使用 `Tab` 和 `Shift+Tab` 依次访问“停着”“认输”“重新开始”和“游戏规则”。获得焦点的操作必须显示强调色边框。
3. 仅使用键盘激活每项操作。在确认框内按 `Escape`，确认对局状态没有变化。

## 终局与重开

1. 停着一次。计数必须变为 `1 / 2`，当前执子方必须切换。
2. 落下一子。停着计数必须恢复为 `0 / 2`。
3. 连续停着两次。此后必须禁止继续落子，结果面板必须显示胜方、胜差、棋子数、领地、贴目和总分。
4. 选择重新开始并取消，确认局面保留；再次选择并确认，确认恢复空棋盘、黑方先行和零停着计数。
5. 开始另一局，选择认输，先取消再确认。结果必须将对手显示为胜方，且不显示计分结果。
